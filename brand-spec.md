# PODBACKEND reference system

Seven-page, warm editorial podcast agency website. The supplied images are the visual authority. Fidelity 10, asset dependence 10, information density 7, visual variance 2, motion intensity 4. Desktop/laptop first composition with responsive mobile layouts.

Coral #ff603c, peach #fff0e9, ink #101211, muted #787d87, white #ffffff. Roboto, self-hosted through Next.js, with tight heading tracking. 8px spacing base, 16–28px card radii, pill buttons, subtle diffuse shadows. Motion is quiet: 450ms reveals, gentle floating cards, pointer-responsive WebGL ribbons, reduced-motion support.

Photographic artwork is generated individually from the visual references and served as standalone full-frame assets from public/assets/generated. No screenshots are used as website images. Platform and client marks are standalone SVG recreations. The PODBACKEND logo uses a coral circle, white waveform, and black wordmark.

Shared header and footer follow the landing-page reference across all routes. References supply visual marketing claims and sample people/stories, not verified business results. No original recordings, course videos, or submission-service credentials were provided.
